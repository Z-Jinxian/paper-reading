# 最新技术选读

## 每轮目标与范围

- 为本站「最新技术」选入一篇值得投入学习时间的代表论文。复用现有板块，每个北京时间自然日使用一个 technologyRecommendation 记录，与每日推荐各自计数，并选择不同论文。
- 检索泛 AI，包括基础模型架构、训练与优化、推理与智能体、多模态与生成、表征与数据、AI 系统与计算效率、AI for Science、机器人与物理智能，以及与 AI 有明确方法联系的交叉技术。候选池按本轮技术进展组织，覆盖不同问题。
- 先查近半年，重点发现近期改变技术路线的新证据。候选不足扩到一年并说明原因。分别记录首发、所读版本、正式发表和证据日期。近期修订不能重置首发日，时效只作同分项。

## 筛选与证据

- 读取 /skills/paper-screening/SKILL.md 与 /skills/paper-reading/SKILL.md。沿用原文核验、实验决策价值、受控比较与独立采用的要求。
- 核验公开全文和一手权威来源。优先权威 AI 顶会主会、相关领域标杆期刊，或权威公司正式公开的研究报告。AI 科学交叉工作核验相应学科的正式期刊与研究资料。分别标注主会、工作坊、期刊和公司预印本，给出通过门槛的官方证据。
- 建立通常至少六篇的候选池，再比较三至五篇短名单。按技术影响与可迁移学习价值、原文证据与公平对照、正式发表层级、独立复现或采用排序。列明主要落选原因、实现可得性与尚缺的证据。
- 选中能解释具体新机制、改变实验或工程判断的论文。检查新做法相对已有方法改变了什么，采用了哪些训练信号、架构、计算或数据假设。产品宣传、排行榜和机构名用于发现线索，结论回到论文与实际实验。
- 使用本站统一的 100 分编辑量尺，实验决策影响 30、证据与对照质量 25、正式发表权威性 15、独立采用或复现 15、长期价值 10、互补性 5。记录各项依据。没有达标候选时报告缺口，继续核验已有记录。

## 技术精读

- 用一两句话交代此前瓶颈，再讲核心思想、数学或架构原因，以及读者学完可以做出的技术判断。选取最值得读的章节，沿原文顺序穿插定位、英文与对应中文、原理、公式、符号和数值例子。
- 遵循本站原文转载与翻译规则。保留同版 PDF 的真实页码、段落位置和原文裁片，使用获准原文或明确标注的自撰释义。
- 重点讲透一至两个公式。用同一组小数字代入，计算中间量，并改变一个变量解释结果。网络或框架是贡献时画结构图，说明输入输出、形状、关键依赖、梯度和训练与推理流程。
- 按论文真实条件说明关键对照、指标、计算或数据预算、结论边界和可证伪的预测。保留独立复现、迁移与工程落地尚缺的证据。
- 为技术概览填写 paradigm 的 name、meaning、change、evidence、limit、source、date。date 记录原始证据日期，选读日期单独写 technologyRecommendation.date。name 使用稳定技术名称，source 为 HTTPS 一手出处。

## 写入与查重

- 按 /skills/paper-updates/SKILL.md 获取本站服务访问并调用接口。GET /api/library 后，先查当日 technologyRecommendation.date，再查 DOI、arXiv ID、标题和链接。当日已有记录时继续补齐同一 ID。
- 入选已在库论文时复用 ID 和当前 revision，补充笔记与技术字段。新论文使用 user-UUID。按 topics 中真实 ID 归档到适用领域或方法专题，泛 AI 交叉论文可放扩展精读或最契合的新专题。
- PUT /api/papers/{id} 使用 multipart/form-data，revision 填当前值，note 填完整笔记 JSON。附 technologyRecommendation={date:北京时间 YYYY-MM-DD,importance:0到100,evidence:候选池、比较与排序依据} 和完整 paradigm，保留旧字段、上传文件、分类与讨论。每篇可保存自己的阅读优先度 readingImportance。
- 当日最新技术选文与当日 recommendation 使用不同论文。已有每日推荐日期继续保留。重试先回读，409 时重新取得 revision 并合并，避免重复实体和覆盖他人更新。

## 写后核验

- 回读 /api/library 验证 ID、revision、technologyRecommendation、paradigm、原文与精读字段。按当日技术标记去重，成功时恰有一篇最新技术选文。
- 读取首页，核对「最新技术」出现技术名称、代表论文的站内链接、选读日期和证据日期，并可打开完整精读。同名技术保留最新概览，各论文记录和既有笔记继续保存。
- 核对每日推荐仍按其独立规则滚动，三个领域板块的成员、排序、筛选和旧链接有效。报告本轮选文、学习价值、写入结果及实际缺口。
