# 行业前沿更新

## 发现与定级

- 执行 /skills/paper-screening/SKILL.md 的“三个行业的前沿追踪”。自动驾驶同时查车辆软件／运营、研究与公开评测；大模型同时查研究博客、模型卡、API／权重及独立评测；具身同时查实验室、真机项目、机器人数据和权重。重要泛 AI 交叉技术仍可作为日常技术精读。
- 每轮分别检索三个领域，覆盖海内外、多种材料与不同机构。优先复核最近 72 小时，增量扫描与上次成功时间重叠 48 小时，每日复查七天；长时间中断从上次成功的窗口按段回补。论文集、arXiv、公司正式账号和源码发布分别检查。新资料先提取能直接证实的一件事，附谁比较了什么、可访问范围及限制。对初创团队或未发论文的公开权重，用官方制品、技术说明和可检验的能力判断。负面证据、回归及真实运营边界变化也应纳入。
- 记录真正公开的是什么。写明官方发布、可获取权重、API、道路测试、商业载客、仿真或真机的适用范围。宣传预告、媒体转载与既有工作复述只作线索。行业影响与证据可信度分开；对安全、成功率和成本数字标明评测者、分母、条件或已知缺口。不为厂牌、发布日期或读者私人项目单独给高分。
- 三个判断共同决定标红：改变一项可说明的能力或部署边界、影响超出单个演示、原始材料能验证该变化已经发生。将理由写入 why。没有相应原始证据就暂缓标红。发现重大项立刻双栏收录；同一日可有任意多个，已选论文不占其名额。

## 写入与断点恢复

- 以本网站为根。用 Sites get_site 获取当前服务访问，仅将 OAI-Sites-Authorization: Bearer 凭据送到本站；所有 API 请求加 x-notebook-request: 1，凭据只在内存使用。先 GET /api/frontier 和 /api/library，读取事件、分领域检查点、当日选文、论文标识与删除状态。
- 按机构、实际版本、发布里程碑、规范一手 URL 与关联论文核对同一事件。并发运行复用稳定的小写英文 ID，例如 organisation-model-version；同一事件的补充证据和纠正更新原 ID，保留首次公开时间。新部署是单独里程碑时在标题和日期中写明新增范围。原论文有精读时附同一 paperId，尊重回收站与用户内容。
- PUT /api/frontier/events/{id} 使用 JSON。填写 revision（新建为 0）、title、domains（driving、models、robotics 中的一个或多个）、kind（论文、模型发布、技术报告、部署更新、开放权重、数据与评测、开源实现、独立验证）、published（带时区的 ISO 时间或 YYYY-MM-DD）、importance（0–100 整数）、major（布尔）、summary、change、evidence、limit、why、sources（多个 {label,url}，首项为稳定原始发布链接）、可选 paperId。按事实写摘要、变化、发现依据、不确定性和评级理由，优先 HTTPS 一手出处。网络超时先回读，409 合并当前 revision；内容未变直接复用，禁止重复刷更新时间。
- 当日常规论文和技术论文继续按 /skills/paper-updates/SKILL.md 使用原笔记接口、recommendation、technologyRecommendation 和 paradigm。论文继续按 /skills/paper-reading/SKILL.md 提供分章节中英、数学／架构、同组算例和适用边界。技术事件无需编造论文、页码或公式，可先发布，再链接完整技术资料。
- 每个领域仅在搜索完成、需要收录的事件已持久化并回读后，PUT /api/frontier/checks/{domain}，JSON 含 checkedAt（检查时间，含时区）、sources（实际核查的 {label,url}）、result（找到的变化或未见达标更新及核查范围）。上游或写入故障不得推进失败领域的检查点，其他领域继续。成功后 GET /api/frontier 核验，次轮按各自检查点补扫。
- 默认两栏每次读取以 84% 重要度加最高 16 分的时效权重排序，时效每七天减半。公开时间与选读、补录或检查时间分别显示。/?order=time 提供严格公开时间倒序。两栏各保持至少十条真实、可溯源的旧新条目。数量不足时优先从已有高质量导读回填为“往期精选”，未达十条继续核验真实材料。无实质新增时保留列表、记录核查，不为日报虚构消息。
- 写后核验 /api/frontier 与首页的两份排序、数量、重点项的相同 ID 及红粗文字、详情及原始链接。检查 /frontier-digest 的 HTML：红色和粗体须直接写在重大标题上，并带【重大进展】；跨栏只出现一次。发送和回执依 /skills/paper-updates/SKILL.md。小时任务无新事件时静默。
